# New Wave Linen Supply

Marketing site for New Wave Linen Supply, a hotel and restaurant linen rental service serving Atlanta, GA, Myrtle Beach, SC, and Charleston, SC.

Static HTML with no build step. Open any file in a browser or serve the folder with any static host.

- `index.html` is a chooser page linking the three design options below.
- `classic.html` is option 1: warm linen white, serif headlines, teal accent.
- `bold.html` is option 2: dark navy and gold, condensed uppercase headlines.
- `coastal.html` is option 3: light sky blue, rounded cards, seafoam and coral.

All three share the same copy and the same quote form, which opens a pre-filled email to info@newwavelinen.com.
